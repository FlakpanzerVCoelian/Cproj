Nel repository è presente la versione penultima, che implementa lo stack con le linked liste doppie
La versione definitiva usa uno array

Struttura generale:
main.c: contiene il corpo principale del programma
checks.c: funzioni di controllo
operandi.c: il file più grosso, contiene la maggior parte delle operazioni
scrivibin.c: gestisce le operazioni su file
stack.c: gestisce le operazioni sullo stack
supporto.c: contiene le funzioni di supporto
strutture.h: definisce le strutture
